# Web Traffic Lead Generation Dataset
This dataset captures anonymized user interactions from different traffic sources to analyze the likelihood of lead generation. It is ideal for training classification models or performing exploratory data analysis (EDA) in marketing analytics.

📂 Dataset Description
The dataset contains user session data with the following columns:

Column	Description
source	The marketing channel (e.g., Taboola, Facebook, Adwords, Influencer)
returning	1 if the user is returning, 0 if new
mobile	1 if the user is on a mobile device, 0 otherwise
country	The user’s country (e.g., US, UK, Canada)
pages_viewed	Number of pages viewed in the session
lead	1 if the session resulted in a lead, 0 otherwise
